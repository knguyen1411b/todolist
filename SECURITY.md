# Security Policy

## Supported Versions
Security updates are currently provided for the latest code on the `main` branch.

## Reporting a Vulnerability
Please report security vulnerabilities privately by emailing: **[ADD_SECURITY_EMAIL]**.

When reporting, include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

Please do not open public issues for security vulnerabilities.
We will acknowledge receipt within 72 hours and provide regular updates until resolved.
